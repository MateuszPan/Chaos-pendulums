### Simulation and Analysis of Chaos in a Double Pendulum System in Python
Author: Mateusz Pandura
The code uses the fourth-order Runge–Kutta method to integrate the equations of motion.
### Contents:
•	animation of 1000 double pendulums (with slightly different initial conditions)
•	comparison of two trajectories (sensitivity to initial conditions)
•	phase space (θ₂, ω₂)
•	correlation and autocorrelation analysis
•	recurrence plots
•	energy analysis (kinetic, potential, total)
### ###Requirements
•	Python 3.x
•	numpy
•	matplotlib
•	pandas
•	seaborn
•	scipy
•	scikit-learn
•	ffmpeg (for saving animations)
#### Note: The simulation of 1000 pendulums is computationally demanding.
If performance issues occur, reduce the number of pendulums.
